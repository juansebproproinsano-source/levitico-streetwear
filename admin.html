Configuración pendiente

Conecta la tienda a tu base de datos

El panel todavía no puede guardar nada porque falta conectar Supabase. Toma unos minutos y solo se hace una vez.

  1. Crea un proyecto en Supabase Entra a supabase.com, crea una cuenta gratuita y un proyecto nuevo.
  2. Ejecuta el esquema Abre supabase/schema.sql, cópialo completo y pégalo en el SQL Editor del proyecto. Pulsa Run.
  3. Crea tu usuario administrador En Authentication → Users, añade un usuario con tu correo y una contraseña. Ese es el acceso al panel.
  4. Completa config.js Copia la Project URL y la clave anon public desde Project Settings → API y pégalas en config.js. Añade también tu WhatsApp, correo e Instagram.
  5. Recarga esta página Con eso el panel queda operativo y podrás cargar tu primer producto.

La guía completa está en SETUP.md, en la carpeta del proyecto.
